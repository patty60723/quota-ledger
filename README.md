# 慢慢花手帳

幫自己控制衝動消費的記帳 App。單一 HTML 檔，用手機瀏覽器開啟即可使用，也可以安裝成 PWA。

## v0.1 功能

- 快速記帳：選類別後立即顯示「記下後本期還剩多少」
- 類別與每月預算上限、快用完／超支提醒
- 固定收支：到收支日在首頁出現待確認，可改金額或略過
- 明細、報表（分類排行、近 6 期收支）
- 設定：週起始日、月預算起始日（1–31，當月沒有這天就用月底）
- 匯入 Google Sheet 下載的 .xlsx、匯出／還原 JSON 備份

## 資料存放

- 在 claude.ai 上開啟時，資料存在該頁面的雲端資料庫（只有擁有者能讀寫），電腦和手機同步。
- 部署成 PWA（或直接開 `index.html`）時，資料只存在那個瀏覽器的 localStorage，不會同步。兩邊的資料可以用「匯出備份／從備份還原」搬移。

## 部署成 PWA（Cloudflare Pages）

1. 登入 Cloudflare → Workers & Pages → 建立 → Pages → 連接到 Git，選 `quota-ledger`。
2. 建置設定：Framework preset 選 None，Build command 留空，Build output directory 填 `/`。
3. 部署完成後會得到 `https://<名稱>.pages.dev`。之後推到 `main` 會自動重新部署。
4. 手機打開該網址：
   - iPhone：Safari → 分享 → 加入主畫面
   - Android：Chrome → 選單 → 安裝應用程式
5. 安裝後即使離線也能開啟與記帳。

**更新版本時**：改完檔案後把 `sw.js` 裡的 `VERSION` 加 1，手機下次開啟（有網路時）才會拿到新版。

## 檔案

- `index.html`：整個 App
- `manifest.json`、`icons/`：安裝到主畫面用的名稱與圖示
- `sw.js`：離線快取
- `TECHNICAL.md`：計算方式、判斷規則與資料結構
- `DEVNOTES.md`：開發流程、使用者偏好、做過的決定與未定案的問題

## v0.2 功能

- 類別可設每筆、單日、每月、每年上限；每筆與單日只提醒，每年以曆年計算
- 分期／分攤（真正的分期付款，或一次付清但想攤到之後幾期，例如兩個月的課程）：總額 ÷ 期數，餘數加在首期；每期計入當期支出並占用該期額度；可提前還清或取消後續期數
- 超支選單：記下會超過每月額度時，選擇跟其他類別借、跟下個月借、動用節省結餘，或先記下稍後處理
- 儲蓄：每月目標儲蓄（首頁顯示可支配金額）；每期結束後，在設定裡勾選的類別沒用完的額度轉入節省結餘（預設跟著提醒開關）
- 年度參考值：依過去紀錄推算一年花費，並標示已記錄幾個月
- 退貨／退款：在原支出上記一筆退款，額度還回該期
- 配色：奶茶（預設，Taupe／Grey Olive／Silver／Parchment／Powder Blush）與存摺綠，深色模式跟著手機
- 匯入 Google Sheet 時一併讀取每筆／單日／每年上限與「分期項目」

## v0.3 功能

- 常用支出／收入：有固定金額的點一下直接記下（5 秒內可復原），金額每次不同的會打開記帳畫面並帶好類別與摘要
- 首頁「快速記帳」顯示最常用的 4 個；記帳畫面最上方一排常用
- 記帳畫面「存成常用」；同摘要、類別、金額 60 天內記了 3 次會詢問要不要存成常用
- 設定「常用項目」可新增、編輯、刪除、手動排序（預設依使用次數）
- 慾望清單（「願望」分頁）：依分數排序（需要／想要、冷靜期、預算夠不夠、期限），每個項目顯示買了之後的預算狀況；「買了」會帶好資料開記帳畫面，可改成分期
- 匯入 Google Sheet 時一併讀取「慾望清單」工作表

## v0.3 之後的更新

### 新使用者與說明
- 第一次開啟有設定引導：收入與發薪日（預算週期預設跟發薪日，可分開設）、挑類別、設預算（每類自己填或先填總額）、每月想存多少
- 使用說明卡片（7 張，條列重點＋畫面示意＋「在哪裡」路徑），引導完成後自動出現，也能在「設定 → 一般」重看
- 第一期從月中開始記時，首頁提示每天可花的會偏高；補記之前的花費或到下一期就恢復正常
- Android 可從設定選單「安裝到主畫面」

### 首頁
- 「今天可以花」：本期預算還剩 ÷ 剩下天數，並先扣掉這期還沒付的固定支出
- 本期預算還剩會再扣掉：
  - 沒設上限的類別（例如醫療）花超過「沒分配的收入」的部分
  - 各類別上限加起來超過「收入扣掉存錢罐」的部分
- 需要注意：超支（可直接處理）→ 已用完 → 快用完，再來是待確認的固定收支與備份提醒
- 這期發現：可能超支、成長最多的類別、跟上期比、想要占比、重複購買、沒花錢的天數、預計結餘、存錢罐相關提醒；單張可在這期隱藏，也能在設定關掉
- 接下來兩週：固定收支、分期、想買的期限、存錢罐存款日；超過 5 筆可展開
- 「今天可以花」的進度條下方寫出「本期預算已用 X%」與「時間過了 Y%」

### 記帳與明細
- 金額旁的小計算機（＋ − × ÷，先乘除後加減，結果四捨五入）
- 分期可輸入總額，或輸入每期金額＋總期數＋這期是第幾期（中途開始記的分期，之前已繳的期數不算）
- 已記下的支出可以在編輯時改成分期（固定收支確認的、用存錢罐付的除外）；原本那筆的超支處理會移除並重新檢查，想買清單的連結會改到分期
- 設定 → 分期 上方顯示這期要付的分期合計，以及之後還要付的金額（只算進行中的分期）
- 固定收支可設必要／需要／想要
- 明細可切換列表或月曆；月曆依當天支出上色（以這個月的中位數為基準分 4 級），點日期看當天紀錄；預設顯示方式與一週起始日可在設定調整
- 搜尋所有紀錄（標題列放大鏡）

### 超支與預算
- 已用完與快用完、超支分開顯示；超支可在首頁或「看懂 → 預算進度」直接處理
- 超支補法：跟其他類別借、跟下個月借、動用已節省結餘；都不夠時才能動用存錢罐這期該存的錢
- 期末轉入已節省結餘的金額，最多只到那一期的「本期預算還剩」（已扣掉超支與沒設上限類別花掉的），不會把花在別處的錢算成省下來；「這期預計結餘」用同樣的上限

### 存錢罐（取代原本的「每月目標儲蓄」）
- 每個存錢罐可命名，每週／每月／每年自動存一筆；每週的照這期實際有幾個存錢日計算
- 所有存錢罐這期要存的加起來，先從預估月收入扣掉，剩下的才是可分配預算
- 目標金額與預估存到時間、使用這筆錢（由存錢罐支付、不動到預算）、存一筆（預算外的錢或從已節省結餘轉入）、存錢罐互轉、停止存入
- 每個存錢罐都有紀錄；存一筆與互轉可刪除（錢已用掉時不能刪）
- 用存錢罐付的支出，刪除或退款時錢會退回存錢罐；刪除過的存錢罐若有錢退回會重新出現
- 舊的「每月目標儲蓄」第一次開啟時會轉成名為「儲蓄」的每月存錢罐

### 看懂
- 支出分類可切換排行／圓餅，預設只看日常支出（不含固定支出），可切換全部支出
- 上方摘要固定寫「日常支出中，花最多的是…」，百分比以日常支出計算，不跟著下面的切換改變
- 預算進度分組：超支、需要注意、其他類別
- 年度參考值：上方是「照目前的存錢計畫和結餘，約可存」（金額獨立一行），下面存錢罐、已節省結餘各一列；各類別全年花費表有自己的小標，推算說明放在表格上方
- 必要・需要・想要的三格做成可點的卡片（有箭頭）；螢幕寬度小於 360 時改成上下三列
- 「想要」近 6 期長條有標題與一句重點（這期與上期的占比、金額並列，不算差額）；長條以最高的一期為頂，這期用實心色；緊急預備金說明移到最下面
- 近 6 期收支圖上方有一句重點（收入比支出多／少多少），刻度與月份字放大

### 想買清單
- 按「買了」會打開記帳畫面，帶好名稱、類別與價格，並提示清單價格；實際價格不同可以直接改，也能改成分期
- 已購入的項目記下實付金額，並顯示比清單價省了或多了多少
- 當天加入的項目顯示「今天加入」

### 固定支出
- 明細裡固定支出的紀錄名稱前有「固定」標籤；記帳畫面可用「固定支出」開關手動修正自動判斷
- 一個類別這期的支出全部是固定支出、而且剛好用完上限時，顯示「已繳清」，不算需要注意；還有剩就照一般類別顯示，多了其他支出就恢復一般提醒
- 「看懂 → 預算進度」每個類別都能點開，「看這期 N 筆」列出這個類別這期的紀錄（含分期），點了可以編輯

### 設定
- 可以點進去編輯的列表（類別、固定收支、分期、存錢罐、已購入）右邊都有箭頭
- 標題旁的建立按鈕統一為「＋ 新增」；前往其他頁面的連結用文字加箭頭（例如「管理 ›」）
- 類別預算分成支出類別、收入類別兩組；收入類別不顯示上限、提醒、轉入已節省結餘與必要／需要／想要
- 可分配預算用明細列出：預估月收入 − 存錢罐每月 ＝ 可分配預算，下方有「調整收入」「調整存錢罐」按鈕
- 可以轉入已節省結餘的類別：選中的有勾勾，並顯示已選幾個
- 資料與備份的順序：資料存放 → 匯出備份 → 還原 → 從 Google Sheet 匯入 → 清除
- 每一項先寫結果：
  - 從備份還原、貼上備份內容還原：**取代**目前所有資料（紅字）
  - 從 Google Sheet 匯入：**加進**目前資料，適合搬過來時用一次；再次匯入會覆蓋同一列的紀錄（類別依名稱比對，App 裡新記的不受影響）

### 其他
- 手機返回鍵（和電腦瀏覽器的上一頁）會先在 App 裡退一層：關掉彈出畫面或說明 → 離開設定頁 → 回到「今天」；在「今天」且沒開任何東西時才離開 App
- 清除所有資料：需輸入「清除所有資料」確認，並提示先匯出備份
- 配色：奶茶、抹茶綠（原本的存摺綠，改成跟 logo 葉子相配的灰綠）、櫻花、霧藍、珊瑚海（活潑、對比強的配色），每種都有淺色與深色版本
- 「必要」固定用藍色，與「需要」的綠色區分

技術上的計算方式、判斷規則與資料結構另見 [`TECHNICAL.md`](TECHNICAL.md)。
