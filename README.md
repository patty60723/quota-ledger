# 慢慢花手帳

在花錢之前，先看懂這筆錢會帶來什麼影響的記帳 App。

- 單一 HTML 檔，用手機瀏覽器打開就能用，也能安裝到主畫面（PWA），離線也能記帳。
- 目前版本：**v73**（2026-10-07）。版本紀錄見[上版資訊](#四上版資訊)。

## 一、產品概念

多數記帳 App 只回答「花了多少」。慢慢花手帳還回答：

- **還能花多少**：首頁直接告訴你「今天可以花」多少。
- **這筆花下去會怎樣**：記帳、想買東西時，先看到這個類別本期會剩多少。
- **超支了怎麼辦**：提供有規則的補法，而不是只顯示紅字。
- **衝動能不能忍住**：想買的東西先放進清單冷靜幾天，決定不買也會記下省了多少。

## 二、商業邏輯

這一章說明 App 的**規則**：什麼情況會發生什麼事。實際的公式、演算法與資料結構見 [`TECHNICAL.md`](TECHNICAL.md)。

### 2.1 預算週期
- 預算以「期」為單位，每期從每月的某一天開始（1–31 日，當月沒有這天就從月底開始）。預設跟發薪日一致，可以分開設定。
- 所有預算、超支、結餘都以「這一期」計算。

### 2.2 類別與預算上限
- 類別分成支出與收入。支出類別可以設定四種上限：
  - **每月上限**：主要的預算，決定可用額度與超支。
  - **每年上限**：以曆年計算，超過時提醒。
  - **每筆上限、單日上限**：只提醒，不影響額度。
- 收入類別沒有上限、提醒與必要／需要／想要的設定。
- 提醒：用到警戒線（預設 80%，可調整）時標「快用完」，剛好用完標「已用完」，超過標「超支」。可以對個別類別關掉提醒。

### 2.3 可分配預算
```
可分配預算 ＝ 預估月收入 − 存錢罐這期要存的
```
- **預估月收入**：有固定收入（例如薪資）就用它；沒有的話用上一期實際記到的收入。
- 各類別每月上限加起來，理想上要等於可分配預算。超過的部分（分配超過收入）會從「本期預算還剩」扣掉。

### 2.4 本期預算還剩、今天可以花
- **本期預算還剩**：所有設了每月上限的類別，額度減掉已用。另外會再扣掉：
  - 沒設上限的類別（例如醫療）花超過「沒分配出去的收入」的部分。
  - 上限加總超過可分配預算的部分。
- **今天可以花**：
  1. 先扣掉這期還沒付的固定支出。
  2. 用今天一早還剩的預算，平均分給剩下的天數（含今天）。
  3. 再扣掉今天已經花的。
- 今天多花了，會顯示「明天起每天約可花多少」。
- 首頁進度條同時顯示「本期預算已用 X%」與「時間過了 Y%」，可以看出花得比時間快還是慢。

### 2.5 超支與補法
某個類別超過每月上限時，可以選擇從哪裡補，**本期總額度不會因此增加**：

1. **跟其他類別借**：那個類別本期的額度減少，超支的類別增加。
2. **跟下個月借**：同一類別下一期的額度先用掉。
3. **動用已節省結餘**：用之前省下來的錢付。
4. **動用存錢罐**：只有在沒有類別可以借、結餘也不夠時才能選；只能動用這期該存的錢，不用還。

也可以先記下、稍後在首頁「需要注意」或「看懂 → 預算進度」處理。只由分期造成的超支一樣可以處理。

### 2.6 已節省結餘
- 每期結束時，有勾選「轉入已節省結餘」的類別，沒用完的額度會存進來（預設跟著提醒開關）。
- 轉入的總額**最多到那一期的「本期預算還剩」**：已經花在超支或沒上限類別的錢，不會被算成省下來。
- 那一期完全沒有紀錄，就不轉入，避免把沒使用 App 的期間整期算成省下。
- 首頁「這期預計結餘」用同樣的上限推算。

### 2.7 存錢罐
- 可以有多個存錢罐，各自命名，每週、每月或每年自動存一筆。每週存的，依這期實際有幾個存錢日計算（4 或 5 次）。
- 所有存錢罐這期要存的合計，先從預估月收入扣掉（見 2.3）。
- 可以設**目標金額**，App 會推算大概什麼時候存到。
- 操作：
  - **使用這筆錢**：由存錢罐支付，不動到預算。
  - **存一筆**：存入預算外的錢（獎金、紅包），或從已節省結餘轉入。
  - **互轉**：把錢移到另一個存錢罐。
  - **停止存入**：保留裡面的錢，不再自動存。
- 用存錢罐付的支出，刪除或退款時錢會退回存錢罐。

### 2.8 固定收支
- 房租、電信、薪資這類每月固定的收支，到了收支日會出現在首頁「需要注意」等待確認。確認後才算進帳；金額不同可以先改；這個月沒有就略過。
- **確認只在首頁做**。「設定 → 固定收支」列表顯示每一項的狀態：
  - **待確認**：黃色標籤。收支日已過但還沒確認，包含之前月份漏掉的，多筆時寫「待確認 N 筆」。
  - 本月已確認（✓）、本月略過、M/D 到期、N 月開始：灰色小字。
  - 有待確認時，列表上方顯示「有 N 筆待確認 · 到首頁確認」，筆數和標籤一致。
- **哪些支出算固定**：由固定收支確認產生的，或跟某個固定支出同類別、而且同名稱或同金額的。每筆紀錄都可以用「固定支出」開關手動修正。明細裡固定支出的名稱前有「固定」標籤。
- **已繳清**：一個類別這期的支出全部是固定支出、而且剛好用完上限時，顯示「已繳清」，不算需要注意。還有剩就照一般類別顯示。

### 2.9 分期／分攤
- 用於真正的分期付款，或一次付清但想攤到之後幾期的費用（例如一次繳兩個月的課程）。
- 總額 ÷ 期數，餘數加在第一期。每一期算進該期支出、占用該期額度。
- 可以輸入總額，或輸入每期金額＋總期數＋這期是第幾期（中途才開始記的分期，之前已繳的期數不算）。
- 已經記下的支出，可以在編輯時改成分期。固定收支確認的、用存錢罐付的除外。
- 可以提前還清，或取消之後的期數。
- 「設定 → 分期」上方顯示「這期要付」與「之後還有」的金額。

### 2.10 想買清單
- 想買的東西先放進清單冷靜，**冷靜期 7 天**。
- 每個項目會評分，依需要或想要、放了幾天、預算夠不夠、購買期限排序，並標出「可以買」「再等等」或「會影響本期預算」，以及「買了之後，這個類別本期還剩多少」。
- **買了**：打開記帳畫面，帶好名稱、類別與價格，可以改實付金額，也能改成分期。記下實付金額，並顯示比清單價省了或多了多少。
- **不買了**：項目保留，記下省了多少（清單價格），可以馬上復原，或之後改回想買。清單上方顯示「今年冷靜後不買，省下 NT$X」。
- 省下的錢不會自動移動：它還在這期的類別預算裡，期末照 2.6 的規則轉入已節省結餘。
- 底部「已決定」列出買了與不買了的項目，以及各幾個、總共省下多少。

### 2.11 必要／需要／想要
- 每筆支出可以標記必要、需要或想要。類別、固定收支、分期都能設預設值，也可以設成每次都問。
- 「看懂」顯示三者的金額與占比、「想要」近 6 期的占比趨勢，以及用必要支出推算的緊急預備金（6 個月）。

### 2.12 看懂與這期發現
- **收支分析**：
  - 支出分類（排行或圓餅），預設只看日常支出，也就是排除固定支出。
  - 必要／需要／想要。
  - 近 6 期收支。
  - 年度參考值：照目前存錢計畫約可存多少，以及各類別全年花費推算。
- **預算進度**：依超支、需要注意、其他類別分組。每個類別都能展開，看這期的每一筆紀錄。
- **這期發現**（首頁卡片）：跟上期同一時間比較。例如可能會超支、花得比上期快、重複購買、沒花錢的天數、這期預計結餘、存錢罐進度。每張卡片可以在這期隱藏。

### 2.13 資料與備份
- **資料存放**：
  - 安裝到主畫面或用瀏覽器打開：只存在那支手機的瀏覽器裡，不會同步。
  - 在 claude.ai 上打開：存在 claude.ai 的資料庫。
  - 兩邊的資料彼此獨立。
- **備份**：
  - 手機上可以「分享」到雲端硬碟、LINE 或 Email，也可以下載。
  - 超過 14 天沒備份，或 3 天以上且新增了 30 筆以上時，首頁會提醒。
- **還原**：從備份檔還原，或貼上備份內容還原，會**取代**目前所有資料。
- **從 Google Sheet 匯入**：**加進**目前資料，適合從試算表搬過來時用一次；再次匯入會覆蓋同一列的紀錄。
- **匯出明細（CSV）**：所有紀錄一筆一列，用 Excel 或 Google Sheet 分析。只能看，不能用來還原。
- **清除所有資料**：要輸入「清除所有資料」才能執行，並提示先備份。

## 三、安裝與使用

### 3.1 打開 App
- 用手機瀏覽器打開 Cloudflare Pages 的網址（`https://<專案名稱>.pages.dev`）。
- 第一次打開會有設定引導：收入與發薪日、挑類別、設預算、每月想存多少。每一步都可以略過，之後在設定裡改。
- 引導完成後會問要不要跟著**導覽**走一遍：畫面變暗、只亮要點的地方，旁邊同時有說明。要操作的步驟（打開記帳、切分頁、進設定）必須點亮處才會前進；純說明的步驟按「知道了」。共 6 段：今天可以花、記一筆、明細、想買清單、看懂、設定（存錢罐與備份），隨時可以跳過，導覽中不會存任何資料。
- 之後可以在「設定 → 一般」重新導覽，或看「說明卡片」（超支怎麼補、固定收支與分期、存錢罐的規則）。

### 3.2 安裝到主畫面
- **Android（Chrome）**：右上角齒輪 →「安裝到主畫面」；或 Chrome 選單 → 安裝應用程式。
- **iPhone（Safari）**：分享 → 加入主畫面。
- 安裝後可以離線使用；手機的返回鍵會先在 App 裡退一層，回到「今天」後才離開 App。
- **建議一定要安裝**：沒有安裝的網頁，瀏覽器在空間不足時可能清除資料，iPhone 尤其明顯。「設定 → 資料與備份 → 資料存放」會顯示目前是否受保護。

### 3.3 從 Google Sheet 搬過來
1. 在 Google Sheet 選「檔案 → 下載 → Microsoft Excel (.xlsx)」。
2. App 裡「設定 → 資料與備份 → 從 Google Sheet 匯入」，選擇檔案。
3. 先看匯入預覽，包括類別、固定收支、分期、想買清單、交易筆數與需要注意的地方，確認後再匯入。

### 3.4 備份建議
- 定期在「設定 → 資料與備份」按「分享」，把備份存到雲端硬碟。只下載到手機的話，手機遺失時備份也會一起不見。
- 換手機時：舊手機分享備份 → 新手機安裝 App →「從備份還原」。

### 3.5 自行部署（Cloudflare Pages）
1. Cloudflare → Workers & Pages → 建立 → Pages → 連接到 Git，選這個 repo。
2. 建置設定：Framework preset 選 None，Build command 留空，Build output directory 填 `/`。
3. 部署完成會得到 `https://<名稱>.pages.dev`。之後推到 `main` 就會自動重新部署。

## 四、上版資訊

### 4.1 上版流程
1. 在功能分支開發，用 `tests/` 的自動測試確認沒有改壞東西：
   ```
   cd tests && npm install && npx playwright install chromium   # 第一次
   npm test
   ```
2. 發佈到 claude.ai 預覽版確認。預覽版有「載入示範資料」可以快速看到各種畫面。
3. 確認後把 `sw.js` 的 `VERSION` 加 1，合併到 `main` 並推送，Cloudflare Pages 會自動部署。
4. 已安裝的手機下次有網路時打開 App，就會拿到新版。如果沒更新，把 App 從最近使用清單滑掉再打開。

小改動（文字、顏色、對齊、間距）可以直接上線；新功能、計算或資料變更、版面調整先放預覽版。詳細流程見 [`DEVNOTES.md`](DEVNOTES.md)。

- P1 持續使用：每日記帳提醒（通知，或首頁顯示連續記帳天數）
