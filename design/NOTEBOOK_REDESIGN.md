# 改版計畫：紙本手帳風格

> 狀態：計畫中（2026-10-08）。先做對照稿確認方向，再分三個階段實作；每個階段都先放預覽版，確認後才上線。

## 一、為什麼要改

目前的畫面功能和資訊都對，但長得像模板產生的 App：

| # | 現象 | 出現的地方 | 問題 |
|---|---|---|---|
| 1 | 所有內容都放在白色圓角卡片裡，加柔和陰影 | 全站 | 典型 shadcn／Tailwind 範本樣子；看懂頁有「卡片 → 切換 → 卡片」的多層包裝 |
| 2 | 每一列前面都有粉彩方塊圖示 | 明細、需要注意、接下來、記一筆類別 | 每家記帳 App 都這樣，佔最顯眼的位置卻只傳達類別 |
| 3 | 藥丸形切換到處都是 | 看懂一頁有 4 組 | 主次切換長一樣，看不出層級 |
| 4 | 深色大卡片＋超大數字 | 首頁「今天可以花」 | 金融科技 App 的標準開場 |
| 5 | 藥丸標籤 | 超支、快用完、可以買、已用完 | 範本預設樣式 |
| 6 | 全站無襯線粗黑體 | 全站 | 已載入的霧光楷體只用在 logo |
| 7 | 底部導覽膠囊底色、圓形浮動按鈕 | 全站 | Material Design 3 預設 |

## 二、方向與原則

**借用紙本手帳與文具的語彙，不做擬真質感。**

1. **紙，不是卡片**：頁面本身就是紙。用細橫線與留白分區；只有「要你處理的事」才浮起來成為卡片。
2. **墨與印章**：狀態用印章表達（台灣人熟悉的印章、發票章），顏色用文具色。
3. **手寫標題、帳簿數字**：標題與日期用楷體；金額用等寬對齊的數字，像存摺。
4. **少一層包裝**：能用文字和分隔線表達的，不包卡片、不加圖示底色。
5. **好讀優先**：楷體不用在內文和金額；所有文字對比度至少 4.5:1（大字 3:1）。
6. **只改外觀**：資料結構、計算、商業規則、`data-*` 屬性（測試與事件依賴）一律不動。

## 三、設計語彙

### 3.1 字體

| 用途 | 字體 | 備註 |
|---|---|---|
| 頁面標題、區塊標題、日期欄、「今天」大日期 | 霧光楷體 LXGW WenKai TC | 需加載 400 字重（目前只載 700）；Google Fonts 依字元切片載入，不會一次下載整套 |
| 內文、說明、按鈕 | Noto Sans TC（不變） | |
| 金額 | Figtree，`tabular-nums`（不變） | 靠對齊做出存摺感，不換成等寬字體以免難讀 |

### 3.2 色彩（文具色）

在現有每套配色上新增語意 token，不新增配色本身：

| token | 用途 | 參考 |
|---|---|---|
| `--ink` | 主要文字、墨線 | 墨黑（沿用 `--ink`） |
| `--pencil` | 次要文字、橫線、刻度 | 鉛筆灰（由 `--muted`、`--line` 衍生） |
| `--seal` | 超支、年度超支、刪除 | 朱紅印泥（沿用 `--stamp`） |
| `--pen` | 收入 | 原子筆藍（沿用 `--income`） |
| `--marker` | 「今天可以花」的螢光筆底線 | 由各配色的 accent 調淡 |
| 類別色 | 只用在帳本列的小色點與圖表 | 沿用 `--t1`～`--t8` 的深色那一組 |

深色模式：紙變成深色紙（沿用各配色深色的 `--paper`），印章與筆色用各配色已有的深色值；全部要重新跑對比度檢查。

### 3.3 元件

| 元件 | 樣子 | 取代 |
|---|---|---|
| **紙面區塊** | 無外框、無陰影；區塊標題（楷體）下一條細橫線 | `.card` 的大部分用法 |
| **待辦卡** | 唯一保留的卡片：需要注意、固定收支待確認、備份提醒 | — |
| **帳本列** | 左側日期欄（例：「8／四」）；名稱 ⋯⋯⋯ 金額（點線導引）；類別改成名稱前的小色點；必要需要想要改成小字 | `.tx` 的圖示方塊 |
| **印章** | 方形或圓形外框、朱紅、略旋轉 −4°～−8°、字是楷體；狀態：超支、已用完、年度超支（朱紅）、快用完（土黃）、已確認（勾）、可以買（墨綠）、不買了（灰） | `.tag` 藥丸 |
| **蓋章動畫** | 確認固定收支、記下一筆、決定不買時，印章縮放 1.3→1、透明 0→1，約 180ms；遵守 `prefers-reduced-motion` | — |
| **尺** | 預算進度條改成細線＋每 10% 一個刻度、時間進度是一個三角指標 | `.hbar`、`.bar` |
| **頁籤** | 主要切換（月報／年報、明細的列表／月曆）做成頁面頂端的索引頁籤 | `.seg` 藥丸 |
| **文字切換** | 次要切換（收支分析／預算進度、排行／圓餅、日常／全部）改成文字＋底線 | `.seg.mini` |
| **底部導覽** | 去掉膠囊底色，作用中的那一格用一個小方印或底線標示 | 目前的 pill |
| **記一筆按鈕** | 圓角方形（像印章的印面），圖示改成筆；位置不變 | 圓形 FAB |

## 四、各畫面

| 畫面 | 改法 |
|---|---|
| **首頁** | 「今天的這一頁」：楷體大日期（10／8 週四）＋「今天可以花」金額，下方螢光筆底線；預算進度改成尺；三個小數字（本期預算還剩、剩下天數、已節省結餘）並排在一條橫線下。需要注意保留為待辦卡，狀態用印章。快速記帳改成一排文字標籤。這期發現、接下來、最近改成紙面區塊 |
| **記一筆** | 金額欄維持大字；類別改成文字＋色點的格子，選中時加墨框；必要／需要／想要改成三個小印章，選中時「蓋上」 |
| **明細** | 帳本列＋日期欄；每天的小計寫在日期欄底部；月曆的日期格用細格線，像手帳月曆頁 |
| **看懂** | 月報／年報用頁籤；收支分析／預算進度用文字切換；摘要改成一段「這個月的筆記」（楷體標題、內文）；圖表沿用現有配色，但外框拿掉 |
| **想買** | 每個願望一張待辦卡（它本來就需要你決定）；狀態用印章；「冷靜 7 天」顯示成手帳上的倒數格 |
| **設定** | 清單維持，但去掉卡片外框，改成紙面＋細線分隔 |
| **引導與導覽** | 歡迎頁加楷體大標；導覽說明框改成便條紙樣式（直角、淡黃底）|

## 五、分階段

### 第 0 階段：對照稿（不動 App）
- 做一頁對照稿：首頁、明細、看懂三個畫面，左邊現在、右邊手帳風，淺色與深色各一組，用示範資料。
- **驗收**：你確認方向，或指出要調整的地方。

### 第 1 階段：字體、文具色、紙面與帳本列
- 加載楷體 400；新增 3.2 的 token。
- 標題與日期換楷體；明細、首頁「最近」、日曆當天清單換成帳本列。
- 大部分 `.card` 改成紙面區塊，保留待辦卡。
- **驗收**：明細一屏可見的紀錄數比現在多至少 30%；所有配色、淺深色、320／390 寬度截圖檢查；測試全部通過。

### 第 2 階段：印章
- 所有狀態標籤換成印章元件；加蓋章動畫。
- **驗收**：每種狀態在每套配色、淺深色下對比度合格；開啟「減少動態效果」時沒有動畫；測試全部通過（測試若依賴 `.tag` 類別要同步更新）。

### 第 3 階段：首頁「今天這一頁」、尺、頁籤、導覽
- 首頁主視覺、尺、頁籤與文字切換、底部導覽、記一筆按鈕、導覽便條紙。
- **驗收**：互動導覽每一步仍亮在正確的元素上（導覽測試會檢查）；返回鍵、選月份等既有流程不變。

## 六、不會動的東西
- 資料結構、儲存、備份格式。
- 所有計算：今天可以花、預算、結算、存錢罐、分期、外幣。
- `data-*` 屬性與 `id`（事件、測試、導覽都靠它們）。
- 6 套配色的名稱與選擇方式。

## 七、待決定
- 印章用方印還是圓印（或依狀態混用）。
- 帳本列要不要保留類別圖示（縮小成單色線條）或只用色點。
- 第 3 階段的頁籤要放在頁面頂端，還是改成側邊索引（側邊比較有手帳感，但窄螢幕會佔寬度）。
