# Quota Ledger SVG Icon Set

Custom monoline SVG resources for the UI refinement.

- viewBox: `0 0 24 24`
- fill: none
- stroke: currentColor
- stroke width: 1.75
- round caps and joins
- category icons: 20–22px in 48–52px pastel tiles
- nav icons: 22–24px
- utility icons: 20px

Use inline SVG or `<svg><use>` after creating a sprite. Decorative category icons should use `aria-hidden="true"`; icon-only controls require an `aria-label`.

The wishlist navigation icon intentionally uses a shopping-bag + heart rather than a gift box, because the destination means “things I want to buy”, not “gifts”.
