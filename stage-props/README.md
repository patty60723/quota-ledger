# 舞台道具排列

給歌唱班同學在舞台上排列道具的單頁網頁。純 HTML/CSS/JS，不需安裝或後端；直接開啟 `index.html` 即可。
資料存在瀏覽器 localStorage，可用右上角「備份／還原」匯出 JSON 跟同學共用。

## 功能
- **事件** ＝ 呈現日期 ＋ 舞台，可無限新增、複製（沿用上次排法）。
- **道具庫**：全域共用，同一道具可跨事件重複使用、同場放多個。類別：劇場提供／個人提供／演員。
- **舞台規格**：自訂場地寬×深（公尺），可新增、編輯。
- **排列舞台**：俯視圖拖曳、方向鍵微調、旋轉、複製。
- **輸出**：全部或個人（或劇場）的道具清單＋俯視圖；列印／PDF、PNG、CSV；可「每人一頁」。

## 搬到獨立 repo
此資料夾自成一體，整個 `stage-props/` 複製出去即可成為新 repo；也可用 GitHub Pages 發佈。
